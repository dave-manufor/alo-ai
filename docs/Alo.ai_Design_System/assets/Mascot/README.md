# Mascot

Jàpá, the grandchild of Ìjàpá from the àlọ́ tales. Fixed colours: `night` shell with `moon` adire circles, green skin, `ink` outlines.

- `japa-happy.svg`: default; start screens and empty states.
- `japa-listen.svg`: while the child speaks; the `sky` waves show Alo.ai is listening.
- `japa-think.svg`: when a child is stuck or an answer missed. Use this, never a sad face.
- `japa-cheer.svg`: stars, badges and the end of a session.

Show at `mascot-m` (160px) or larger on kid screens, uncropped, with half his height of clear space. Never on grown-up report data.

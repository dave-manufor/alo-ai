# Icons

24px grid, 2.5px rounded strokes, `ink` outlines plus one palette fill (duotone): `mic` (sky), `replay` (coral), `star` (moon), `lantern` (moon and coral), `book` (white), `check` (leaf).

These files are fixed-colour and read on `surface` and `surface-raised` in the Day theme. Components draw single-colour versions in `currentColor` for use on fills and in the Night theme.

# RewardBadge

A medallion for an effort milestone. Pass `kind` (`brave`, `teller`, `collector` or `listener`) and `earned`.

- Badges reward effort and curiosity, never scores or speed.
- Earned badges are `moon` with a press edge; locked ones are dashed outlines with "Keep reading to unlock".
- Show a newly earned badge with Jàpá's `cheer` pose and the star chime.

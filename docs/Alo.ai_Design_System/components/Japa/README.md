# Japa

Jàpá, the mascot, in four poses. Pass `pose` (`happy`, `listening`, `thinking` or `cheer`) and an optional CSS `size`.

- `happy` on start screens, `listening` while the child talks, `thinking` when a child is stuck or misses an answer, `cheer` for rewards and the end of a session.
- Never sad, never mocking, never recoloured or cropped. At least `mascot-m` wide on kid screens.
- Kid mode only; never next to report data.

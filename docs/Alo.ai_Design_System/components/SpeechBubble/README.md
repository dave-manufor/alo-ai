# SpeechBubble

Auntie Kemi's words on screen, with the Alo.ai mark as her avatar. Pass the line as children.

- `tone="say"` for ordinary lines, in `kid-body`.
- `tone="call"` for the session-opening "Àlọ́ o!", large, in Andika and `coral-text` on `coral-soft`. Use it once per session.
- Show every line Auntie Kemi speaks, so a grown-up can follow. Keep lines to eight words or so.
- Never use a bubble for scores or grown-up information.

# ReadingPanel

The story a child reads aloud, set in Andika on `surface-raised`. Pass `text` (a string or a list of sentences), an optional `title` and a `level`.

- `level` picks the reading size: `p1` for ARL 1–2, `p3` for ARL 3–6, `p5` for ARL 7–12. Width is capped at `measure-reading`.
- During an assessment, show the text plainly: no highlighting, no animation, no timer, and never mark errors on it.
- Left-aligned, never justified or italic. Nothing else on the screen moves while a child reads.

# LanternStreak

Weekly reading streak as lanterns. Pass `weeks`, oldest first, `true` for a week with at least one session.

- Weekly, not daily, so no child is pushed to play every day.
- A missed week is a **resting** lantern, never an empty or broken one, and the copy stays kind: "Your lanterns are resting. Light one this week!"
- Never warn a child that a streak will be lost.

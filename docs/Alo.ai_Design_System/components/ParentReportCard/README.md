# ParentReportCard

The grown-up summary of a session for parents. Pass `title`, `date`, `summary`, `stats` (label and value pairs), `workingOn`, `tip` and an optional `action` with `onAction`.

- Grown-up mode: `title`, `body`, `label` and `caption` type, no mascot, no bounce.
- Lead with a strength, then one thing to work on, then one thing to do. The summary comes from the Reading Coach and has already passed the guardrail validator.
- Use the stats the report provides, nothing calculated in the UI. Never show percentiles or profile codes to parents.

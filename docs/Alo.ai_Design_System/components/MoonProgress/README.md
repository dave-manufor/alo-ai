# MoonProgress

Where the child is in the session, as moons along a path: done steps are green with a check, the current step glows gold, and later steps are empty rings. Pass `steps` and the `current` index.

- Default steps: Chat, Read, Tell, Questions, Listen. Drop "Listen" when the listening story doesn't run.
- Each state differs in shape as well as colour (check, glow, ring), and screen readers hear "(done)" and "(now)".

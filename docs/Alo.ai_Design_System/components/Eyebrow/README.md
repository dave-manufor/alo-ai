# Eyebrow

A small uppercase label above a value or a group ("Last check", "Try this week"). Grown-up mode only. `label` type at 13px, `ink-muted`.

- It names a thing; it is not a heading. Use a real heading for the section title.
- Pass `as` to change the tag (default `span`). Field and ToggleGroup use the same look for their labels.

# RoundButton

A round `night` button with an arrow (`kind="next"`, the default) or a triangle (`kind="play"`). Use it to turn a story page or play a clip. `label` is required: it is the only text a screen reader gets.

- Kid mode. The size is `tap-kid` (64px), never smaller, even where a design shows 56px.
- It sits on a soft `night` glow rather than a press edge, so it reads as a gentle "go on" and not as the one primary action. Keep the screen's single `primary` Button if there is one.
- Reduced motion: no press animation.
